# MISSION 03 — LEARNING OBJECTIVES

By the end of Mission 03, you should be able to demonstrate the following.

## Python

- Run a `.py` file.
- Create variables.
- Recognize strings, integers, floats, booleans, lists, and dictionaries.
- Use `print()` and `input()`.
- Convert strings to numbers.
- Use `if`, `elif`, `else`, `and`, and `or`.
- Use `for` loops.
- Create functions, pass arguments, and return values.

## Files and Data

- Read, write, and append text files.
- Explain JSON at a basic level.
- Load and save JSON.
- Explain CSV at a basic level.
- Read CSV using Python.
- Convert CSV text values into numbers when needed.

## Error Handling

- Explain what an exception is.
- Use `try` and `except`.
- Handle invalid numeric input.
- Handle missing keys.
- Handle malformed JSON.
- Allow later valid records to continue processing.

## Bash

- Use variables.
- Capture command output.
- Use a basic `if` statement.
- Use a basic `for` loop.
- Run Python from Bash.

## Engineering

- Separate input, processing, output, and logging.
- Test code in small steps.
- Commit meaningful progress with Git.
- Avoid hard-coding values that should come from input.

## Completion Standard

You are ready for Mission 04 when you can take a JSON telemetry file and build a Python program that loads it, evaluates readings, handles bad records, generates a report, creates structured output, logs errors, and continues processing useful data.
