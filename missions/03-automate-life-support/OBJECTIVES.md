# MISSION 03 — LEARNING OBJECTIVES

By the end of Mission 03 you should be able to:

- Run Python 3 on Ubuntu Server.
- Use variables, strings, integers, floats, booleans, lists, and dictionaries.
- Use `if`, `elif`, `else`, `and`, and `or`.
- Use `for` loops.
- Create functions and return values.
- Read, write, and append files.
- Load and save JSON.
- Read CSV data.
- Handle `ValueError`, `KeyError`, `TypeError`, and malformed JSON.
- Create Bash scripts with variables, conditions, and loops.
- Launch Python from Bash.
- Push code from Earth Mission Control and pull/run it on LUNA-1.
