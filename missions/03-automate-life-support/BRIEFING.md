# ⚙️ MISSION 03 — AUTOMATE LIFE SUPPORT

**MISSION ID:** LUNA-M03  
**PRIORITY:** CRITICAL  
**ROLE:** Junior Systems Engineer  
**OBJECTIVE:** Build LUNA-1's first automated telemetry-processing system

---

## Mission Briefing

LUNA-1 is online. Mission Control can remotely administer the station and track engineering changes with Git and GitHub.

But the station still depends too heavily on humans.

Environmental systems continuously produce measurements such as oxygen, temperature, pressure, power, and communications status. A person cannot realistically inspect every sensor reading forever.

LUNA-1 needs software that can:

1. Read telemetry.
2. Evaluate readings.
3. Detect abnormal conditions.
4. Continue when individual records are bad.
5. Generate reports.
6. Save processed data for later systems.

During this mission, you will learn enough **Python, Bash, JSON, CSV, and error handling** to build that system yourself.

Nothing required by the final project should depend on programming syntax that was never introduced during the mission.
