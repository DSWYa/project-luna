# LAB 03 — FRONTEND FETCH

Create:

```text
static/lab.html
static/lab.js
```

The HTML page must contain:

- heading,
- status area,
- button,
- results container.

When the button is clicked, JavaScript must use:

```javascript
fetch()
```

to retrieve one API endpoint and display returned information.

Concepts already introduced:

```text
document.getElementById
document.createElement
textContent
appendChild
fetch
response.json
```

Goal:

```text
browser → API → database → JSON → browser
```
