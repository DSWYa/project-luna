# MISSION 05 — LEARNING OBJECTIVES

By the end of this mission, you should be able to demonstrate:

## HTTP

- Explain client and server.
- Explain request and response.
- Explain `GET` and `POST`.
- Recognize common HTTP status codes.
- Explain JSON in an API.

## FastAPI

- Create a FastAPI application.
- Create routes.
- Return JSON.
- Use path parameters.
- Use query parameters.
- Accept a JSON request body.
- Use a Pydantic model.
- Use FastAPI's automatic `/docs` interface.

## PostgreSQL Integration

- Connect Python to PostgreSQL with Psycopg 3.
- Execute SQL.
- Retrieve rows.
- Return database results as JSON.
- Use parameterized SQL instead of concatenating user input.

## Frontend

- Create HTML.
- Apply basic CSS.
- Load JavaScript.
- Use `fetch()` to call an API.
- Update a page using JSON data.

## Linux Deployment

- Create a Python virtual environment.
- Install dependencies.
- Run FastAPI on LUNA-1.
- Create a systemd service.
- Inspect logs with `journalctl`.
- Configure Nginx as a reverse proxy.
- Explain which service owns each port.

## Troubleshooting

Identify whether a problem exists in:

```text
browser
network
Nginx
FastAPI
application code
SQL query
PostgreSQL
```
