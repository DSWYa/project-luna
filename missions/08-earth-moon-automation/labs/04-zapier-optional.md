# LAB 04 — OPTIONAL ZAPIER COMPARISON

This lab is **optional**.

It is not required for Mission 08 completion.

Use it only if your current Zapier account exposes the necessary webhook trigger without payment or a required paid trial.

## Objective

Build the simplest possible two-step automation:

```text
Webhook trigger
↓
One action
```

Possible action:

- add a test row,
- send a test email,
- or another free action visible in your account.

Send JSON from LUNA-1.

Map at least:

```text
station
source
severity
message
```

Compare the Zapier field-mapping UI with the Apps Script code you wrote.

## Skip Condition

If Zapier displays:

```text
Premium
Upgrade required
Trial required
```

stop.

Mark this lab:

```text
SKIPPED — PLAN LIMITATION
```

and continue.

Project LUNA remains fully completable without Zapier.
