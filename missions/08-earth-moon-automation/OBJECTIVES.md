# MISSION 08 — LEARNING OBJECTIVES

By the end of Mission 08, you should be able to:

## Automation Concepts

- Explain trigger and action.
- Explain event-driven automation.
- Explain webhook.
- Explain webhook sender and receiver.
- Explain JSON payload contract.
- Explain why HTTP 200 alone does not always prove a workflow produced the intended business result.

## Google Apps Script

- Create a Google Sheet automation log.
- Open a bound Apps Script project.
- Create `doGet(e)`.
- Create `doPost(e)`.
- Parse JSON POST data.
- Return JSON.
- Use Script Properties.
- Validate a shared token.
- Append a spreadsheet row.
- Send an email.
- Deploy a script as a web app.
- Create a time-driven trigger.

## LUNA-1

- Test outbound HTTPS.
- Send JSON with `curl`.
- Send JSON from Python.
- Store webhook URL/token outside source code.
- Add automation variables to Docker Compose.
- Trigger automation from FastAPI.
- Handle relay failure without losing the primary application action.

## Operational Design

- Avoid exposing LUNA-1 unnecessarily.
- Protect shared secrets.
- Understand cloud-service quotas.
- Troubleshoot sender, network, receiver, payload, and downstream action separately.

## Optional Zapier Skills

- Recognize trigger/action workflows.
- Understand two-step workflow limitations.
- Test a webhook trigger only if available on the account without requiring payment.
