INCIDENT INC-001 — HINT 1

Mission Control reports:

PING: SUCCESS
SSH: SUCCESS
WEB DASHBOARD: FAILED

This means:

The server is running.

The network connection is working.

Remote administration is working.

The failure appears to be more specific than a full server outage.

Ask yourself:

What component is responsible for providing the webpage?

Investigate that component before changing anything.
