MISSION 01 — LEARNING OBJECTIVES
You are not expected to memorize every command in this mission.
You are expected to understand what the commands are doing and become comfortable finding information when you need it.
By the end of Mission 01, you should be able to explain or demonstrate the following without following the tutorial line-by-line.

Virtualization
- Explain the difference between a host and guest operating system.
- Explain what a virtual machine is.
- Create, start, stop, and snapshot a VM.
- Explain why VMs are useful for labs and testing.
Linux
- Navigate the Linux filesystem.
- Determine your current directory.
- List files and directories.
- Create directories.
- Create, copy, move, and delete files.
- Read text files.
- Edit text files from the terminal.
- Understand absolute and relative paths.
- Explain the purpose of sudo.
- Identify your current user.
- Understand basic Linux file permissions.
Processes and Services
- View running processes.
- Explain the difference between a program, process, and service.
- Check whether a service is running.
- Start, stop, and restart a service.
Networking
- Explain what an IP address represents.
- Explain the purpose of a subnet mask/prefix.
- Explain the purpose of a default gateway.
- Explain DNS at a basic level.
- Explain the difference between TCP and UDP.
- Explain what a network port is.
- Identify your server's IP address.
- Test whether another device is reachable.
- Perform a DNS lookup.
- Test an HTTP service.
SSH
- Explain what SSH is used for.
- Identify the standard SSH port.
- Connect to another computer through SSH.
- Exit an SSH session.
- Explain why remote administration is important.
Web Services
- Explain the basic client/server model.
- Install a web server.
- Check whether the service is running.
- Access the web server from another computer.
- Identify the standard ports associated with HTTP and HTTPS.

Mission Completion Standard
You are ready to move forward when you can:
- Start your LUNA-1 VM.
- Determine its IP address.
- SSH into it from your host computer.
- Check the health of its SSH and web services.
- Access its status page from your host browser.
- Create and modify files without needing a graphical interface.
- Troubleshoot a basic service failure.
You do not need to memorize everything.
You need to know enough to ask:
"What should I check next?"

That question is one of the most valuable skills in technology.
