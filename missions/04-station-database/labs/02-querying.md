# LAB 02 — QUERYING

On **LUNA-1**, use the telemetry table to answer:

- reading count,
- lowest oxygen,
- highest temperature,
- average pressure,
- readings below 19.5 oxygen,
- three lowest oxygen readings,
- average oxygen by module ID,
- average oxygen by module name.

Use `COUNT`, `MIN`, `MAX`, `AVG`, `WHERE`, `ORDER BY`, `LIMIT`, `GROUP BY`, and joins.
