# MISSION 04 — LEARNING OBJECTIVES

You should be able to:

- Install PostgreSQL on Ubuntu.
- Check its Linux service.
- Use `sudo -u postgres psql`.
- Create databases and users.
- Create tables and choose common data types.
- Use primary and foreign keys.
- Insert, select, update, and delete safely.
- Use `WHERE`, `ORDER BY`, and `LIMIT`.
- Use `COUNT`, `AVG`, `MIN`, `MAX`, and `GROUP BY`.
- Use `INNER JOIN` and `LEFT JOIN`.
- Understand `NULL`.
- Run `.sql` files on LUNA-1.
- Import CSV with `\copy`.
- Use transactions and rollback.
- Rebuild a database from Git-tracked SQL.
