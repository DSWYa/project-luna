# LAB 01 — CONTAINER OPERATIONS

Perform this lab on **LUNA-1**.

Use an Nginx image.

Requirements:

1. Pull the image.
2. Run it detached.
3. Give it a custom name.
4. Publish it on a host port other than 80.
5. Verify it from Earth.
6. View logs.
7. Execute `nginx -v` inside the container.
8. Stop it.
9. Start it again.
10. Remove it.
11. Prove the image still exists.

Explain the difference between:

```text
image
container
```
