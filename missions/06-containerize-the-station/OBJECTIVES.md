# MISSION 06 — LEARNING OBJECTIVES

By the end of Mission 06, you should be able to:

## Docker Fundamentals

- Explain image vs container.
- Pull an image.
- Run a container.
- List running containers.
- List all containers.
- Stop and remove a container.
- Inspect container logs.
- Execute a command inside a container.

## Networking

- Publish a container port.
- Explain host port vs container port.
- Create a Docker network.
- Explain service-name DNS inside Docker networks.
- Explain why `127.0.0.1` inside a container refers to that container.

## Storage

- Explain ephemeral container filesystems.
- Create a named volume.
- Mount a named volume.
- Explain bind mounts.
- Persist PostgreSQL data.

## Images

- Write a Dockerfile.
- Explain `FROM`, `WORKDIR`, `COPY`, `RUN`, and `CMD`.
- Build an image.
- Run a container from a custom image.

## Compose

- Explain a Compose service.
- Read a `compose.yaml`.
- Start a stack with `docker compose up`.
- Stop a stack with `docker compose down`.
- Build services.
- View logs.
- Inspect service state.
- Use health checks.
- Use `depends_on`.
- Use environment variables.
- Use named volumes.
- Use Docker networks.

## Migration

- Containerize the Mission 05 API.
- Containerize PostgreSQL.
- Containerize Nginx.
- Preserve database data.
- Retire replaced host services safely.
